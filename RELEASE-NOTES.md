**Rhema is alpha-quality software, shared as-is with no liability** (the MIT license disclaims all warranty). It is built for one working poet first and tested on her books, not hardened for the world — expect rough edges, keep your own backups, and please file issues for anything you hit.

Binaries: Linux AppImage (x64 + arm64), Windows installer + portable, macOS dmg + zip (arm64 + x64, unsigned — right-click → Open past Gatekeeper). The `latest*.yml` files are the in-app updater channels; leave them in place.
